# Design Rules - SiBibit Sumbawa

UI harus mengikuti PRD dan design system project.

## Prinsip
- sederhana
- jelas
- konsisten
- responsive
- mudah digunakan
- mendukung desktop dan mobile

## Pemda
Dashboard, program, anggaran, kampus, validator, monitoring, validasi, laporan, fraud, dan audit.

## Kampus Mitra
Profil, pendamping, wilayah, procurement, SPJ, distribusi, dan monitoring.

## Pendamping
Penerima bantuan, distribusi, foto, GPS, tanda tangan, monitoring, dan sinkronisasi offline.

## Validator
Laporan, filter wilayah, verifikasi lapangan, foto GPS, validasi, fraud, dan revisi.

## State UI
Tangani:
- loading
- empty
- error
- success
- offline
- syncing
- validation error

Jangan membuat keputusan bisnis baru melalui UI.

Jangan menentukan warna, font, radius, atau visual token baru jika belum ditentukan oleh design system.
