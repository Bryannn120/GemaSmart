# Markdown Rules - SiBibit Sumbawa

Gunakan Markdown yang rapi, konsisten, dan mudah dibaca.

Gunakan struktur:
# Judul
## Bagian
### Subbagian

Gunakan code block untuk kode.

Gunakan tabel Markdown untuk data terstruktur.

Gunakan istilah PRD secara konsisten:
- Pemda
- Kampus Mitra
- Pendamping Lapangan
- Validator Lapangan
- SPJ
- NIK
- KK
- Geotagging
- Survival Rate
- Audit Trail
